# Revisit — {Project Name}, week {N}

> **How to use this file** — Revisit weeks (every 5th). No new project: re-architect the project from four weeks ago, working from its original `requirements.md`, on a `revisit-w{N}` branch **in that project's own repo**. Copy this template in as `revisit.md`.
> **Do not re-read the original `design/decisions.md` until the new design is finished.** The whole value is in what I arrive at independently now versus what I arrived at then. Reading first contaminates it, and there is no way to un-see it.
> Then run `git diff` on `decisions.md` — the comparison is literal, no tooling required — and re-run `/evaluate` against the same sealed reference and the same scorecard.
> Done when: the new design is complete, the diff is analysed below, and the re-scored result is recorded in the hub's projects log — run `/log-project` in the hub, which completes the `revisit` row `/kickoff` already created.
